SLA Instance Info Lookup

The CLI now supports detailed SLA instance lookups, including instance status, completion time, slowest path, target task instances, etc. Based on this information, your personal Agent can analyze bottlenecks and provide optimization suggestions.
02

Kafka Topic Request Management

Submit and track Kafka permission, bandwidth quota and retention size adjustment requests.
03

Resource Governance Integration

Get the details for HDFS assets and Presto/Batch YARN governance tasks via CLI.

Explore non-Hive downstreams of a Hive table via CLI.

Expanded DataHub Task Management

Users can create, operate, and maintain ingestion task types through the CLI, including:

Kafka-to-HiveHive-to-HiveMySQL-to-HiveMySQL-to-Paimon

Interactive and Batch Support for Non-SQL Spark Workloads (Shortcut Commands)

Expanded support includes +sql batch mode and interactive and batch shortcut commands for +python and +scala.

Shortcut commands combine multiple operations into a single command.
06

Graph Management

Key updates focus on creating, updating, and safely deleting graph spaces and vertex/edge models.
