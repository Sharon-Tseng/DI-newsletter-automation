01

SLA 实例详情查询

CLI 现已支持查询 SLA 实例详情，包括实例状态、完成时间、最慢路径、目标任务实例等。基于这些信息，你的个人 Agent 可以分析瓶颈并提供优化建议。
02

Kafka Topic 申请管理

提交并跟踪 Kafka 权限、带宽配额及保留容量调整申请。
03

资源治理能力集成

通过 CLI 获取 HDFS 资产及 Presto / Batch YARN 治理任务的详情。

通过 CLI 查询 Hive 表的非 Hive 下游依赖。
04

DataHub 任务管理扩展

通过 CLI 创建、操作和维护以下类型的数据集成任务：

Kafka-to-HiveHive-to-HiveMySQL-to-HiveMySQL-to-Paimon
05

非 SQL Spark 作业：interactive 与 batch 快捷命令（Shortcut Commands）

新增支持 +sql batch 模式，以及 +python 和 +scala 的 interactive 与 batch 快捷命令。

快捷命令可将多个操作合并为一条命令。
06

Graph 管理

重点支持 Graph 空间及顶点／边模型的创建、更新和安全删除。

即将推出

10 月 即将上线

01

可扩展的数据导出

Diana 现支持将 Query Step 结果导出为 CSV、Excel 或 Google Sheet。大规模数据通过可复用快照和可恢复的后台任务处理，并明确展示行数限制、截断原因及权限校验结果。

即将上线
02

智能跨 Topic 路由

Topic Router 会判断问题能否由当前 Topic 回答，或是否需要补充其他 Topic。系统执行查询前，用户可以查看并确认建议范围；同时可通过 @ Topic 搜索和引用有权限访问的 Topic。

03

可分享的 Report 追问会话

通过“Continue in Chat”产生的 Report 追问会话现在会作为标准 Chat Session 处理。Owner 可沿用现有 Session Share 流程进行分享，被分享者则可以安全地以只读方式查看完整的追问历史。
